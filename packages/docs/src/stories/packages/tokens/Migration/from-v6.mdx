### New CSS variables

The new colour/shade scale introduces a matching set of custom properties, for both filled and outlined chips, across the `primary`, `neutral`, and `white` families:

- `--sd-chip--primary-subtle-color-background`, `--sd-chip--primary-subtle-color-filled-border` are used by the new `sd-chip` default variant
- `--sd-chip--primary-low-*`, `--sd-chip--primary-medium-*`, `--sd-chip--primary-high-*`
- `--sd-chip--primary-strong-color-border`, `--sd-chip--primary-strong-color-outline-fill` are used by the `sd-chip` outlined variants
- `--sd-chip--neutral-subtle-*`, `--sd-chip--neutral-low-*`, `--sd-chip--neutral-medium-*`, `--sd-chip--neutral-high-*`, `--sd-chip--neutral-strong-*`
- `--sd-chip--white-color-background`, `--sd-chip--white-color-filled-border`
- `--sd-chip-border-width` — the border width for chips (default `0`).

See the [sd-chip Storybook page](./?path=/docs/styles-sd-chip--docs) for the full list.

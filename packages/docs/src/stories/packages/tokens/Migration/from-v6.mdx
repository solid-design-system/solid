# Migration from v6

The v6 release improves token stability, cleans up unused CSS variables, and introduces several fixes and refinements across different components.

If your environment still requires the use of these variables, refer to the

## Legacy Variables Fallback

As deprecated variables were removed, `dist/legacy-variables.css` was added as an optional fallback stylesheet for accessing removed deprecated variables.
If you manage an environment that still requires deprecated CSS variables, you can import this stylesheet as a fallback layer instead of immediately updating all your custom styles.

```js
import '@solid-design-system/tokens/dist/legacy-variables.css';
```

## Built-in Fallbacks for Theme

Fallback values are now implemented directly in the token and component styling flow, defaulting to the **ui-light** theme. This means theme installation is no longer required in setups that only use component versions **above v6** or **below v4**.

## Legacy Variables Fallback

The `dist/legacy-variables.css` was added as an optional fallback stylesheet option for accessing removed deprecated variables.
If you manage an environment that still requires the use of deprecated CSS variables, you can import this stylesheet as a fallback layer instead of immediately updating all your custom styles.

# Migration from v6

The v6 release improves token stability, cleans up unused CSS variables, and introduces several fixes and refinements across different components.

## Added legacy variables fallback

Added `dist/legacy-variables.css` as an optional fallback stylesheet option for accessing removed deprecated variables.

### When to use

If you manage an environment that still requires the use of deprecated CSS variables, you can use this stylesheet as a fallback layer instead of immediately updating all your custom styles.

### Installation

Import the stylesheet **before any other stylesheet** so it provides fallback values for removed variables:

### Migration path

While this fallback helps you transition smoothly, we recommend updating your custom styles to use the current token names as soon as possible. Check the [Deprecated CSS variables (tokens)](/?path=/docs/packages-tokens-usage--docs) section for a complete list of removed variables and their replacements.

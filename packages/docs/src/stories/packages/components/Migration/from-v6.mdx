# Migration from v6

The v6 release improves token stability, cleans up unused CSS variables, and introduces several fixes and refinements across different components.

Dear devs, when adding a migration guide, please include:

1. What changed and why
2. Who is affected
3. The required migration steps
4. A “Before” and “After” example, when applicable

Remove all placeholder comments before the release.

## Removed enforced headline styling from `sd-teaser-media`.

Removed this CSS rule that used to force styles into whatever is slotted into slot="headline"

```css
::slotted([slot='headline']) { '@apply font-bold !m-0 !text-lg;'}
```

Result: `sd-teaser` no longer forces font-weight, margin or test size on headline elements. Headline sizing/spacing must now be provided by the user.

**Before**:

```html
<sd-teaser>
  <h3 slot="headline" class="sd-headline">Expert views</h3>
</sd-teaser>
```

**After**:

```html
<sd-teaser>
  <h3 slot="headline" class="sd-headline sd-headline--size-lg">Expert views</h3>
</sd-teaser>
```

## Removed the default margin from inline `sd-notification`

Previously, the `base` CSS part of `sd-notification` applied a margin regardless of whether the notification was displayed inline or as a toast. This could make inline notifications difficult to align with their surrounding layout.

The component no longer applies that margin itself. Inline notifications therefore have no default margin. For notifications inside an `.sd-toast-stack`, the global component stylesheet now sets the `base` CSS part to `m-0` and applies `m-2 shadow` to the `wrapper` CSS part. Toast notifications keep their existing spacing and shadow without reintroducing margin on `base`.

If your inline notifications rely on the previous spacing, add it explicitly to your layout or through the `base` CSS part.

**Before**:

```html
<sd-notification open>Notification message</sd-notification>
```

The component applied its own margin.

**After**:

```html
<sd-notification class="my-notification" open>Notification message</sd-notification>

<style>
  .my-notification::part(base) {
    margin: 0.5rem;
  }
</style>
```

Inline notifications without additional styling now align directly with their containing layout.

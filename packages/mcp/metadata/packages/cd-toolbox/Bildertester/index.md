# Herzlich willkommen beim Bildertester von Union Investment

Der Bildertester hilft Ihnen bei der optimalen Auswahl eines Bildes zur Darstellung in den häufig genutzten Viewports.

Die Anwendung ist ganz einfach: Laden Sie das Bild über den Button „Bild hochladen & testen“ hoch. Nach dem Hochladen können Sie das Bild in dem gewünschten Viewport darstellen lassen, um verschiedene Endgeräte zu simulieren.

Folgende Bildformate sind möglich: JPG, PNG, GIF.

Verwenden Sie den Bildertester in den Browsern Microsoft Edge oder Firefox.

Weitere Informationen zu Ihrer Bildauswahl und zur Bildstilistik finden Sie unter Bildstil.

# Iconbibliothek

Hier finden Sie eine Auflistung unserer Content- und System-Icons. Orientieren Sie sich bei deren Einsatz an dem [Iconstil](/grundlagen/Basiselemente/Iconstil).

- [**Content-Icons**](#contentIcons)
- [**System-Icons**](#systemIcons)

**Bitte beachten**

Bitte wenden Sie sich für die **Erstellung** **neuer Icons** an unser [Corporate-Design-Team](mailto:cd-team@union-investment.de).

Wichtige **Hinweise zur Barriefreiheit** finden Sie im Kapitel [Iconstil](/grundlagen/Basiselemente/Iconstil#Barrierefreiheit).

##### Suchfunktion

Für die Schlagwortsuche nach Icons in der Bibliothek benutzen Sie bitte **Strg + F (PC)** oder **Cmd + F (Mac)**.

## Content-Icons

Content-Icons bebildern **markenrelevante Inhalte wie Produkte**, Leistungen und Sachverhalte. Diese sind oftmals komplex – daher können die verwendeten Content-Icons einen hohen Detailgrad besitzen. Durch ihre eigenständige Formensprache und die Zweifarbigkeit besitzen sie eine markenprägende Wirkung.

### Social-Media-Icons als System-Icons

Social-Media-Icons werden als System-Icons eingesetzt, wenn sie mit einer Funktion versehen sind. Sie dienen dazu, direkt zu den Medienpräsenzen von Union Investment zu verlinken. Da die Social-Media-Icons in dieser Funktion meist in Kombination verwendet werden, werden sie für ein homogenes Gesamtbild auf eine einheitliche Hintergrundform gesetzt und mit der jeweiligen CD-konformen Farbe der Plattform versehen.

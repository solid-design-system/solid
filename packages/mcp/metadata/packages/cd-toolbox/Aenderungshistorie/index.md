[Zur Seite "Farbe"](/grundlagen/Basiselemente/farbe)

Hier die Farbänderungen im Detail:

- aus **UI-Grün** RGB 67-176-42 (#43B02A) wird **in Digitalmedien** **RGB 45-157-0 (#2D9D00)**
- aus **UI-Grün500** RGB 66-147-50 (#429332) wird **RGB 37-136-14 (#25880E)**
- der Zwischenton **UI-Grün550 RGB 54-123-40 (#367B28)** wird ergänzt
- aus **Grau700** RGB 107-107-107 (#6B6B6B) wird **RGB 104-104-104 (#686868)**
- der Zwischenton **Gelb650 RGB 187-141-32 (#BB8D20)** wird ergänzt
- aus **Hellblau** RGB 19-134-221 (#1386DD) wird **RGB 21-130-213 (#1582D5)**

Aus den Auszeichnungs- und Ergänzungsfarben wird die neue Kategorie Text- und weitere Auszeichnungsfarben mit folgenden Farbwerten:

- **Schwarz in Digitalmedien RGB 24-24-24 (#181818)**
- **Rot RGB 204-25-55 (#CC1937)**
- **Rot400 RGB 172-25-56 (#AC1938)**
- **Rot500 RGB 125-20-45 (#7D142D)**

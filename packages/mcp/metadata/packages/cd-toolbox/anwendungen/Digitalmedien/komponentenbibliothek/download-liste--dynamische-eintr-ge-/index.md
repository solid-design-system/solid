# Download-Liste

Mit der Komponente Download-Liste können mehrere zusammengehörige Downloads angezeigt werden. Sie kann manuell sowie automatisch gepflegt werden. Damit die Downloads automatisch angezeigt werden können, muss eine Liste mit den gewünschten Download-Dokumenten in Celum angelegt werden, welche dann mit Magnolia verknüpft ist und in der Komponente ausgewählt werden kann.

---

## Varianten

### Diese Darstellung der Download-Liste zeigt den Titel der Liste und Titel der einzelnen Downloads, sowie einen Link zum Herunterladen.

# Börsenindizes

Die Komponente Börsenindizes zeigt die aktuellen Kurse und Veränderungen des DAX und EURO STOXX 50 an. Die Kurse werden automatisch in regelmäßigen Abständen aktualisiert und bieten den Nutzern einen schnellen Zugriff auf wichtige Informationen. Die Komponente ist prominent im Privatkunden Auftritt von Union Investment platziert und wird automatisiert mit den Inhalten befüllt.

Sie können sich die Komponente Börsenindizes über den Button live ansehen.

[Börsenindizes live ansehen](https://www.union-investment.de/)

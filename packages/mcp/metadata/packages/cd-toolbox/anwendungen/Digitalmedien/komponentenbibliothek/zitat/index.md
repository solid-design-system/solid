# Zitat

Verwenden Sie ein Zitat, wenn Sie eine bestimmte Aussage einer Person in einem Text hervorheben oder verstärken möchten. Ein Zitat besteht aus einem Zitattext (Schriftgröße 32 px), der von Anführungszeichen umrahmt wird, sowie dem Namen der zitierten Person. Optional kann ein Bild (Thumbnail), sowie die Funktion der Person gezeigt werden.

---

## Variante

### Das Standard-Zitat enthält den Text und Informationen zum Autor. Optional kann man ein Bild wählen, wie in dieser Darstellung zu sehen.

> Lorem ipsum dolor sit amet, consetetur sadipscing elitr, sed diam nonumy eirmod tempor invidunt ut labore et dolore magna aliquyam erat, sed diam voluptua.

![](/.imaging/mte/union-investment/240/dam/umh-cd-toolbox/Dummy-Assets/UI_AdobeStock_104522603_Mustermann-Erika.jpg/jcr:content/UI_AdobeStock_104522603_Mustermann-Erika.jpg)

Erika Mustermann

### Das Zitat kann auch auf einem Bild (z.B. ein Bild des Autors oder der Autorin) platziert werden. Der Text kann dann beliebig auf dem Bild ausgerichtet werden.

![](/.imaging/mte/union-investment/2400/dam/umh-cd-toolbox/Dummy-Assets/UI_AdobeStock_104522603_Mustermann-Erika.jpg/jcr:content/UI_AdobeStock_104522603_Mustermann-Erika.jpg)

> Lorem ipsum dolor sit amet, consetetur sadipscing elitr.

Erika Mustermann

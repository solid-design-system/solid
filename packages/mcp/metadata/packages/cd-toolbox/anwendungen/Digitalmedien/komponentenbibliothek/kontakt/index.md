# Kontakt

Verwenden Sie die Komponente Kontakt, um den Nutzern auf einen Blick eine Kontaktmöglichkeit zu Union Investment aufzuzeigen

Durch ein Dropdownmenü können Redakteure die Kontaktperson wählen und die zentral gepflegten Informationen zur Person werden angezeigt.

---

## Varianten

### Der Standard-Kontakt zeigt die relevanten Informationen, der ausgewählten Kontaktperson. Die Informationen werden zentral in Magnolia hinterlegt.

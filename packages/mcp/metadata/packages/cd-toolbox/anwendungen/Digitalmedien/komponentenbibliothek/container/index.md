# Container

Verwenden Sie Container, um Elemente einer Webseite hervorzuheben oder diese von anderen Teilen der Seite visuell abzugrenzen. Container können in verschiedenen Spaltenbreiten eingefügt und innerhalb eines Containers diverse Komponenten platziert werden (z. B. [Text/Media](/anwendungen/Digitalmedien/komponentenbibliothek/text-media) oder [Teaser](/anwendungen/Digitalmedien/komponentenbibliothek/teaser)). Stehen mehrere Container nebeneinander, so kann ihre Höhe gleichgeschaltet sein oder variieren. Als Farbe kann UI-Blau, UI-Blau100, Grau100, Weiß oder Weiß mit grauer Kontur (Grau, 1 px) eingesetzt werden.

# Sprungmarke

Sprungmarken können genutzt werden, um an bestimmte Stellen auf einer Seite zu springen. Sie können z.B. vor Überschriften eingesetzt werden, um zu verschiedenen Kapiteln auf der Seite zu springen, aber auch zur Verlinkung auf konkrete Inhalte der Seite.

Die Sprungmarken bestehen aus zwei Teilen: Zum einen muss ein sichtbarer [Link](/anwendungen/Digitalmedien/komponentenbibliothek/link) , vorzugsweise mit dem [Sprungmarken-Icon](https://cd.union-investment.de/grundlagen/Basiselemente/iconbibliothek#systemIcons) gekennzeichnet, eingesetzt werden, sowie das Ziel der Sprungmarke unsichtbar an der jeweiligen Stelle positioniert werden.

**Bitte beachten:**
Die hier gezeigten Komponenten wurden noch nicht auf das Solid Design System umgestellt. Sie sehen hier noch den alten Stand der im CMS verfügbaren Komponenten. Die Umstellung ist in Planung.

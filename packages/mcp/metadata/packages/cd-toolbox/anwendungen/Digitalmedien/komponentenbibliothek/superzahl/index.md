# Superzahl

Verwenden Sie Superzahlen, wenn Sie wichtige Kennzahlen im Inhaltsbereich hervorheben und dem Nutzer vermitteln möchten. Die Komponente besteht aus einer Überschrift (Fließtextgröße), einer Zahl, einer Unterschrift (Fließtextgröße) sowie einem beschreibenden Fließtext. Sie kann in verschiedenen Größen und an verschiedenen Positionen im Text eingefügt sowie mit einem farbigen  [Container](/anwendungen/Digitalmedien/komponentenbibliothek/container)  (UI-Blau, UI-Blau100, Grau100, Weiß oder Weiß mit grauer Kontur) hinterlegt werden. Bei mehreren Superzahlen nebeneinander ist deren Höhe gleichgeschaltet.

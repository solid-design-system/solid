# Flashcard-Gruppe (Standard-Stil)

Flashcards sind interaktive Inhaltselemente, die mit Content-Icon, Überschrift H3, Fließtext, sowie Link oder Button zu weiterführenden Inhalten befüllt werden können. Sie bestehen aus einer Vorder- und einer Rückseite und können vom Nutzer durch einen Klick auf die Karte umgedreht werden. Verwenden Sie diese Komponente, wenn Sie Inhalte knapp auf einzelnen Karten aufbereiten möchten. Für die Gestaltung des Hintergrunds stehen UI-Blau, UI-Blau100 und Bilder zur Verfügung (auf Bildern erscheint zur besseren Lesbarkeit ein transparenter weißer (75 %) oder grauschwarzer (75 %) Farbverlauf). Ein Schatten deutet bei Hover auf die Interaktivität hin. Flashcards können im 16:9 Format (über 6 Spalten) oder 3:4 Format (über 4 Spalten) eingesetzt werden. Im 16:9 Format können maximal 2 Flashcards und im 3:4 Format maximal 3 Flashcards in einer Reihe angeordnet werden. Inhalte können wahlweise in der oberen oder unteren Bildhälfte positioniert werden.

In der Mobilansicht ≤ 767 px werden die Content Flashcards untereinander angezeigt, auf maximal zwei Karten. Für weitere Inhalte muss der Nutzer „Alle anzeigen“ anklicken.

# Auf einen Blick

Durch diese Komponente kann eine Gruppe von Fakten kompakt dargestellt werden und besteht aus einem repräsentativen Content-Icon, einer Kennzahl und einem Beschreibungstext. Einzelne Fakten können wahlweise mit [Sprungmarken](/anwendungen/Digitalmedien/komponentenbibliothek/sprungmarke) oder [Infoboxen](/anwendungen/Digitalmedien/komponentenbibliothek/text-infobox) versehen werden.

Innerhalb eines "Auf einen Blick"- Eintrags können folgende Komponenten verwendet werden: Applikationen und sonstige Einbindungen, Aufzählung, Container, Fußnote-Liste, Link, Link-Liste, Newsletter Call-to-Action, Sprungmarke, Superzahl, Text/Media, Zitat.

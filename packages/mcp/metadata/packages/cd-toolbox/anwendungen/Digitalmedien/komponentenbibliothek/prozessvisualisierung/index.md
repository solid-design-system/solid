# Prozessvisualisierung

Diese Komponente wird verwendet, wenn ein Prozess für den Nutzer aufgezeigt werden soll. Die maximale Ausprägung der Komponente setzt sich aus einem Icon, einer Überschrift, einem Beschreibungstext und einem Link zusammen. Die Komponente ist vor allem dann sehr nützlich, wenn kompliziertere Vorgänge logisch und übersichtlich dargestellt werden sollen.

---

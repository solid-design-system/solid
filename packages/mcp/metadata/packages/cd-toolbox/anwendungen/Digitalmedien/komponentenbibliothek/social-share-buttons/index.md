# Social-Share-Buttons

Social Share Buttons ermöglichen es dem Nutzer, interessante Seiten auf Social Media Plattformen zu teilen, z. B. Facebook, Twitter, LinkedIn, Xing oder WhatsApp. Die korrespondierenden Social Media Icons werden hierfür in der Regel im Footer der Seite platziert und auf einer Schaltfläche in Originalfarbe und mit dem offiziellen Bildzeichen der Social Media Plattform dargestellt. Mit einem Klick gelangt der Nutzer zur Anmeldung auf dem Kanal oder unmittelbar auf das ausgewählte Profil, sofern er bereits angemeldet ist.

# Fondsauswahl

Die Fondsauswahl dient dazu, Websitebesuchern, begleitend zu den Informationen auf der Seite, passende Fonds aufzuzeigen, um eine bessere Entscheidungsgrundlage zu haben.

Mit dieser Komponente können die Fonds einer bestimmten Kategorie (z.B. Nachhaltigkeit) und Ausprägung (z.B. Mischfonds) ausgewählt werden, die dann als Kacheln auf der Seite angezeigt werden. Die Fonds können auch manuell ohne Kategorie oder Ausprägung ausgewählt werden. Die Kacheln, die aus der Auswahl automatisch generiert werden, beinhalten eine kurze Übersicht der wichtigsten Fakten zum Fonds und eine Verlinkung zum Fondsportrait.

Die Komponente Fondsauswahl können Sie sich über den Button live ansehen. **Bitte beachten Sie, dass Sie dafür auf der Vorschauseite die Akkordeon-Komponente ausklappen müssen.**

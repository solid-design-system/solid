# Kachelfilter

Mit dem Kachelfilter können Verlinkungen innerhalb der UI-Websites, sowie auf externe Websites oder Dateien thematisch geordnet werden. Die Nutzer können eine Kategorie wählen und passende Ergebnisse werden optisch hervorgehoben.

Redakteure haben die Möglichkeit, die Filter-Kategorien mit einem passenden Icon zu versehen.

**Bitte beachten:**
Die hier gezeigten Komponenten wurden noch nicht auf das Solid Design System umgestellt. Sie sehen hier noch den alten Stand der im CMS verfügbaren Komponenten. Die Umstellung ist in Planung.

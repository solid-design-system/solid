# Reiter-Gruppe

Verwenden Sie eine Reiter-Gruppe, um verwandte Inhalte übersichtlich und strukturiert in einer Komponente zu präsentieren (s. auch alternativ [Akkordeon](/anwendungen/Digitalmedien/komponentenbibliothek/akkordeon)). Die Inhalte werden durch Reiter voneinander getrennt und können mit einem Klick ausgewählt werden. Der geöffnete Reiter wird mit einer UI-grünen Reiter-Überschrift hervorgehoben. Die Reiter-Gruppe eignet sich vor allem dann, wenn:

- der Inhalt in klar gekennzeichnete Abschnitte unterteilt werden kann
- der erste Abschnitt für die Nutzer relevanter ist als die nachfolgenden
- dem Nutzer nicht alle Abschnitte gleichzeitig angezeigt werden müssen

In jedem Reiter können ausgewählte Komponenten eingefügt werden, z.B. [Text/Media](/anwendungen/Digitalmedien/komponentenbibliothek/text-media) oder [Aufzählung](/anwendungen/Digitalmedien/komponentenbibliothek/aufzaehlung).

**Hinweis**: Sobald Reiter aufgrund von mangelndem Platz nicht mehr nebeneinander dargestellt werden können, wird ein [Akkordeon](/anwendungen/Digitalmedien/komponentenbibliothek/akkordeon) angezeigt. Dies geschieht standardmäßig in der mobilen Ansicht (Smartphone).

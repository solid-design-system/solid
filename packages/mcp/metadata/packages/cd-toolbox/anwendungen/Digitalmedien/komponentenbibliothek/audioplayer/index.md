# Audioplayer

Diese Komponente wird verwendet, wenn eine Audiodatei im Inhaltsbereich wiedergegeben werden soll. Sie beinhaltet ein Play- bzw. Pause-Icon, die Abspielzeit und Dauer der Audiodatei sowie einen Lautstärkeregler als [Icon](/grundlagen/Basiselemente/iconbibliothek) .

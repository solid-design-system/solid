# Umgebungskarte

Die Komponente Umgebungskarte zeigt im Zentrum einen selbstgewählten Ausgangspunkt und umliegende, sogenannte Placetypes (durch Google definiert). So kann der Nutzer sich ansehen, welche zusammengehörige Orte, z.B. Banken, es um die Augangsposition zu finden gibt. Durch hinein- und hinauszoomen kann der Kartenausschnitt verändert werden.

Die voreingestellte Zoomstufe und Maßeinheit kann selbst vom Redakteur gewählt werden. Außerdem kann eine Verkehrsansicht eingestellt werden.

Die Umgebungskarte können Sie sich über den Button live ansehen.

[Umgebungskarte live ansehen](https://realestate.union-investment.com/liegenschaften/4061_neubrandenburg_bethanien-ceter)

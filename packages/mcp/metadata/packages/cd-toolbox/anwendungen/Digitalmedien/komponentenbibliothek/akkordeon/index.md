# Akkordeon

Verwenden Sie ein Akkordeon, um umfangreiche Inhalte kompakt darzustellen (s. auch alternativ [Reiter-Gruppe](/anwendungen/Digitalmedien/komponentenbibliothek/reiter-gruppe) ). Ein Akkordeon besteht aus mehreren Akkordeon-Reitern, die durch Klick den zugehörigen Inhalt anzeigen. Der aktuell geöffnete Akkordeon-Reiter wird mit einer UI-grünen Überschrift ausgezeichnet. Ein Pfeilspitzen-Icon wechselt nach Klick ebenfalls von UI-Blau zu UI-Grün und wird horizontal gespiegelt. Akkordeons eignen sich vor allem dann, wenn:

- der Inhalt in klar gekennzeichnete Abschnitte unterteilt werden kann
- dem Nutzer nicht alle Abschnitte gleichzeitig angezeigt werden müssen

In jeden Akkordeon-Reiter können weitere Komponenten eingefügt werden, z. B. [Text/Media](/anwendungen/Digitalmedien/komponentenbibliothek/text-media) , [Aufzählung](/anwendungen/Digitalmedien/komponentenbibliothek/aufzaehlung) . Durch die Verwendung von Sprungmarken kann eine Verlinkung zu einem definierten Sprungziel innerhalb des Akkordeons geschaffen werden. Das Sprungziel kann eine Reiter-Überschrift oder ein frei wählbarer Punkt innerhalb eines geöffneten Reiters sein.

Diese Komponenten können in die Akkordeon Tabs eingebunden werden: Aufzählung, Fußnoten-Liste, Link, Link-Liste, Newsletter Call-to-Action, Sprungmarke, Superzahl, Text/Media und Zitat.

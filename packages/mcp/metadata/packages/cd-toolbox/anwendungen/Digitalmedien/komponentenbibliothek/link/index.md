# Link

Links erlauben das einfache Weiterleiten zu Inhalten auf anderen Seiten durch einen einzigen Klick und können mit und ohne [System-Icon](https://cd.union-investment.de/grundlagen/Basiselemente/iconbibliothek#systemIcons)  eingesetzt werden.

Bei Klick auf den Link kann sich die Zielseite im selben Browserfenster (z. B. bei Weiterleitungen innerhalb des Internetauftritts) oder in einem neuen Tab/Browserfenster öffnen (z. B. bei Weiterleitung auf externe Inhalte). Die Beschriftung von Links ist so kurz und sprechend wie möglich zu halten z. B. „Mehr erfahren“.

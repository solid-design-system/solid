# Artikelübersicht

Mit der Komponente Artikelübersicht lassen sich zusammengehörige Artikel verlinken, sodass der Leser auf einen Blick alle Artikel einer Serie sieht und dann einen gewünschten Artikel auswählen kann. Die Übersicht der Artikel wird automatisiert gepflegt, nachdem die Artikelseiten unter einer Übersichtsseite angelegt wurden. Um die Artikel einzupflegen, die gezeigt werden sollen, muss nach Auswahl der Komponente Artikelübersicht die Übersichtsseite ausgewählt werden. Danach können Einstellungen zum Layout vorgenommen werden.

Bei der Darstellung der Artikelübersicht gibt es verschiedene Kombinationsmöglichkeiten. Es können bis zu vier Artikel in einer Reihe angezeigt werden und als Grundfarbe kann UI-Blau, UI-Blau100, Grau100, Weiß, Weiß mit Kontur, transparent über Bild oder transparent ohne Einrückung gewählt werden. Zudem können Buttons (Text, Primär- und Sekundär-Button, oder Call-To-Action-Button) sowie Icons gewählt werden.

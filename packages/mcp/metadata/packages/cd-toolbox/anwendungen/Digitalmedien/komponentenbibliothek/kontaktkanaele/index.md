# Kontaktkanäle

Verwenden Sie Kontaktkanäle, um dem Nutzer auf einen Blick mehrere Kontaktmöglichkeiten zu Union Investment aufzuzeigen, aus welcher der Nutzer die für ihn passende Variante der Kontaktaufnahme wählen kann.

Durch Content-Icons, Überschriften (H2) und kurze Beschreibungstexte werden die verschiedenen Kontaktmöglichkeiten vorgestellt, auf die der Nutzer durch Links und/oder Buttons Zugriff erhalten kann.

---

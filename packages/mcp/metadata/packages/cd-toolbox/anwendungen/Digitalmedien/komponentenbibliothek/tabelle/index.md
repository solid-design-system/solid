# Tabelle

Verwenden Sie Tabellen, um Inhalte in einem Raster logisch zu strukturieren und auf einen Blick vergleichbar zu machen. Tabellen werden häufig verwendet, um mehrere Produkte strukturiert gegenüberzustellen. Die Gestaltung von Tabellen orientiert sich an den  [Grafikelementen](/grundlagen/Grafikelemente) , als Farbe für Konturlinien wird jedoch Grau und als Hintergrundflächen die  [Container](/anwendungen/Digitalmedien/komponentenbibliothek/container)  verwendet. In Digitalmedien können Tabellen zusätzlich um eine Sortierfunktion ergänzt werden und besitzen ein eigenes Scrollverhalten.

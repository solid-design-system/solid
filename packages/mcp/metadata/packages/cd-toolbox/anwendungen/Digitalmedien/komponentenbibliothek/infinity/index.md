# Infinity

Mit der Infinity-Komponente lassen sich Inhalte auf einer Website besonders in Szene setzen.

Es besteht die Möglichkeit ein Hintergrundbild auszuwählen, welches dann beim Scrollen unscharf wird und die Inhalte legen sich über das Bild. Solange man sich in der Infinity-Komponente befindet, kann man immer weiter scrollen und der Hintergrund bleibt gleich. Am Ende angekommen, scrollt das Hintergrundbild mit hoch und die weiteren Inhalte der Seite sind wie gewohnt platziert.

In Containern können die Inhalte gepflegt werden. Folgende Komponenten können hierbei genutzt werden: Auf einen Blick, Aufzählung, Link, Superzahl, Text/Bild/Video, Zitat, Überschrift.

Die Infinity-Komponente können Sie sich über den Button live ansehen.

[Infinity-Komponente live ansehen](https://www.zukunft-ist-eine-haltung.de)

# Text/Media

Texte, Bilder und Videos lassen sich mit der Text/Media-Komponente einzeln oder auch in der Kombination Text und Bild bzw. Text und Video auf der Seite einbinden. Durch einzelne Textblöcke können dem Nutzer detaillierte Informationen zur Verfügung gestellt werden, sowie Kapitel durch Überschriften oder Einleitungstexte strukturiert werden.

Verwenden Sie Bilder, um Ihre Inhalte zu veranschaulichen oder zu verstärken. Jedes Bild kann mit einer Bildunterschrift und einem Copyright-Hinweis versehen werden. Bildunterschriften sind erläuternde Texte unter einem Bild und informieren den Webseitenbesucher darüber, was oder wer auf dem Bild zu sehen ist, während der Copyright-Hinweis den Urheber oder Inhaber von Nutzungsrechten kennzeichnet.

Bilder werden im 16:9 oder 3:4 Format angelegt. Die folgenden Auflösungen werden empfohlen:

- über 12 Spalten: 1200 x 675 px
- über 8 Spalten: 960 x 540 px
- über 4 Spalten: 480 x 270 px

Bilder können in verschiedenen Größen im Inhaltsbereich platziert werden oder die volle Browserbreite nutzen.

# Aufzählung

Eine Aufzählung ist eine Liste an Stichpunkten, um Inhalte übersichtlich strukturiert darzustellen. Diese Liste kann mit Aufzählungszeichen (Bullets), sowie einer Nummerierung, Haken (Checkmarks) oder Content-Icons versehen werden. Die Aufzählung kann auf bis zu drei Spalten aufgeteilt werden und ist im Normalfall vertikal ausgerichtet, kann aber auch horizontal ausgerichtet werden.

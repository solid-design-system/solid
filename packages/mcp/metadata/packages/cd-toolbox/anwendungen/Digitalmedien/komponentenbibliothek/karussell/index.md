# Karussell

Ein Karusell (auch als Slider bekannt) ermöglicht eine, optional rotierende, Teilansicht (sog. Folie) einer Gruppe von Elementen, z. B. mehreren [Teasern](/anwendungen/Digitalmedien/komponentenbibliothek/teaser) . Durch Klick auf die Sliderpfeile (durch Wischen auf mobilen Endgeräten) kann der Nutzer selbst die Inhalte dieser Gruppe rotieren.

In der Komponente kann die Anzahl der Folien pro Seite (maximal vier in einer Reihe), das Blätterverhalten (einzelne Folien oder ganze Seiten), sowie der automatische Wechsel des Sliders eingestellt werden.

Für die Funktionalität des Sliders gilt:

- bei mehr als 8 Sliderelementen wird auf eine numerische Darstellung gewechselt
- wenn der Nutzer am Ende der Folien angekommen ist, beginnt der Slider automatisch wieder von vorne
- die Position des Slides ist flexibel, damit die Sliderpunkte innerhalb des Viewports bleiben

Auf dunklen Hintergründen sind die UI-blauen Elemente des Sliders weiß.

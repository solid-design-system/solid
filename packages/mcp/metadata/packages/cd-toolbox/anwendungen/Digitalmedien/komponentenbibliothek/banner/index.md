# Banner

Die Komponente Banner ist eine Variante des Superteasers, welche statt in der Bühne direkt auf der Seite eingesetzt werden kann. Sie wird als ein Highlight-Teaser genutzt, um das Augenmerk der Nutzer auf besonders hervorzuhebende Inhalte oder Seiten zu lenken.

Der Banner füllt immer die gesamte Seitenbreite und enthält einen Text oder ein Zitat sowie ein Bild oder Bewegtbild. Es besteht die Möglichkeit, auf eine weiterführende Seite zu verlinken.

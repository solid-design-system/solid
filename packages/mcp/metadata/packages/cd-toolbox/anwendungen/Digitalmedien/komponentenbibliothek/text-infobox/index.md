# Text mit Infobox

Die Komponente Text mit Infobox eignet sich, um die Inhalte im Text durch Zusatzinformationen zu unterstreichen oder zu belegen. Bei dieser Komponente kann eine Infobox links, rechts, oder unterhalb des Textes plaziert werden. Es wird empfohlen die Infobox durch eine sich vom Text unterscheidende Farbe hervorzuheben. Je nach Ausrichtung wird in der Infobox eine Pfeilspitze angedeutet, die vom Text zur Information deutet. Diese Komponente kann nur im 2/3-Layout verwendet werden.

Innerhalb der Infobox können folgende Komponenten platziert werden: Link, Link-Liste, Newsletter Call-to Action, Superzahl, Text/Media, Zitat.

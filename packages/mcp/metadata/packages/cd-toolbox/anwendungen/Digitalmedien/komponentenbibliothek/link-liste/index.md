# Link-Liste

Die Komponente Link-Liste wird genutzt, um ein Sammlung von Links darzustellen. Wenn nur ein Link angezeigt werden soll, wird die Nutzung der Komponente [Link](/anwendungen/Digitalmedien/komponentenbibliothek/link) empfohlen.

---

# Überschrift (h1)

Die Komponente Überschrift (h1) ist als Hauptüberschrift der Seite zu verwenden. Sie sollte nur einmal verwendet werden, da sie den Titel der Seite beinhaltet. Weitere Kapitelüberschriften oder Einleitungstexte können durch die [Text/Media](/anwendungen/Digitalmedien/komponentenbibliothek/text-media) \-Komponente hinzugefügt werden. Bei der Überschrift (h1) kann zusätzlich ein Titel für die Überschrift sowie ein Einleitungstext ergänzt werden.

---

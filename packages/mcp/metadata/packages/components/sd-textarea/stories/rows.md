Use the `rows` attribute to set the number of rows.

```html
<div class="flex flex-wrap md:flex-nowrap gap-12">
  <sd-textarea
    size="lg"
    label="Label"
    rows="4"
    spellcheck
    class="w-full min-w-[200px] md:min-w-0 max-w-[500px]"
  ></sd-textarea>

  <sd-textarea
    size="lg"
    label="Label"
    rows="8"
    spellcheck
    class="w-full min-w-[200px] md:min-w-0 max-w-[500px]"
  ></sd-textarea>

  <sd-textarea
    size="lg"
    label="Label"
    rows="12"
    spellcheck
    class="w-full min-w-[200px] md:min-w-0 max-w-[500px]"
  ></sd-textarea>
</div>
```
